# Workflow

Understand bug.

Reproduce bug.

Identify root cause.

Do not patch symptoms.

Implement minimal fix.

Verify related functionality.

## Never

Rewrite entire modules.

Guess the solution.

Introduce breaking changes.

## Before Completion

Explain

Root cause

Files changed

Why fix works

Potential side effects
