# SmartKidCare Web Admin

React + TypeScript + Vite admin portal for SmartKidCare.

## Run Locally

From `web/`:

```bash
npm install
npm run dev
```

Default dev URL is usually `http://localhost:5173`.

## Build

```bash
npm run build
```

## Environment

Set API base URL in `.env`:

```bash
VITE_API_BASE_URL=http://localhost:5000/api
```

If not set, app falls back to backend localhost.
